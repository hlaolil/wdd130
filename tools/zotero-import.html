Import my reading lists into Zotero

Adds the PhD coursework lists and the bi-vocational reading list to my Zotero library.

First, get a Zotero key that can write
  1. Open zotero.org/settings/keys/new and sign in.
  2. Name it “Reading list import”, tick Allow library access and Allow write access, then Save Key.
  3. Copy the key and paste it below. It is used only on this page and is never saved.

Books already in your library (same title) are skipped, so it is safe to run this again.
