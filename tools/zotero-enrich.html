Add summaries and covers in Zotero

Fills in each reading's summary (Abstract) and cover picture from published sources.

How it works

For each book it looks up the publisher's description and cover on Google Books and Open Library; for journal articles it takes the published abstract from OpenAlex. A match is used only when the title and author agree. The summary goes into Zotero's Abstract field (its source is noted in Extra), and the cover link and ISBN are saved so BookHub can show the picture. Items that already have a summary keep it. You can stop and run it again later; it carries on where it left off.
